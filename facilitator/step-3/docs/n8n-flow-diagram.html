The Switch, verbatim

Three rules, one field, string equality. Any other value falls through to nothing.

out0  $json.priority equals "low"     → AUTO_REPLY
out1  $json.priority equals "medium"  → INVESTIGATE
out2  $json.priority equals "high"    → ESCALATE  (SLA 30 min)

The coordinator's system message is one line: "Always talk with the Customer Reply Agent and with the Risk Agent." The tool nodes get their input through $fromAI('Prompt__User_Message_'), so the model decides what each specialist sees.
